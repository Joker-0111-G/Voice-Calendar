## 🎯 项目简介

**Voice-Calendar** 是一个以**语音交互为核心**的日历管理工具。用户只需说出自然语言指令，系统就能自动理解意图并完成日程的**添加、删除、查询**等操作，彻底解放双手。

### 一句话概括

> 说句话就能管日程 —— 不用打字、不用点来点去。

### 核心流程

```
用户语音 / 文字输入
       │
       ▼
    DeepSeek LLM 解析意图
   ┌─────────────────────┐
   │ "下周五晚上7点       │
   │  跟女朋友吃饭"       │
   └────────┬────────────┘
            ▼
   ┌─────────────────────┐
   │ {                   │
   │   action: "add",     │
   │   title: "跟女朋友吃饭",│
   │   time: "2026-06-05  │
   │          19:00",     │
   │ }                   │
   └────────┬────────────┘
            ▼
     数据库 CRUD 操作
            ▼
   ┌─────────────────────┐
   │ "已为您添加日程：     │
   │  跟女朋友吃饭，      │
   │  时间：2026-06-05    │
   │  19:00"             │
   └─────────────────────┘
```

## 🔍 用户痛点与需求分析

### 传统日历的痛点

| 场景            | 传统操作                                                     | 有多麻烦               |
| --------------- | ------------------------------------------------------------ | ---------------------- |
| **记一个日程**  | 打开日历 → 选日期 → 填表单 → 选时间 → 输标题 → 设提醒 → 保存 | **7 步操作，约 30 秒** |
| **查日程**      | 打开日历 → 翻到那天 → 看列表 → 数时间                        | 零碎时间里操作不便     |
| **删日程**      | 找到事件 → 点进去 → 找删除 → 确认                            | 步骤多，容易点错       |
| **改时间**      | 找到事件 → 点编辑 → 改时间 → 保存                            | 比新建还麻烦           |
| **开车/做饭时** | 没法操作手机                                                 | ❌ 完全不能用           |

### 语音方案的优势

```
你说："下周五晚上7点跟女朋友吃饭"
系统自动：解析日期、时间、标题 → 添加 → 语音回复

你说："我这周六有什么安排"
系统自动：查询数据库 → 汇总 → 语音播报
```

**一句话：把 7 步操作变成 1 句话。**

## ✨ 核心功能

### 已实现

| 功能               | 说明                                   | 指令示例                    |
| ------------------ | -------------------------------------- | --------------------------- |
| **🎤 语音添加日程** | 通过自然语言添加事件，自动解析日期时间 | "下周五晚上7点跟女朋友吃饭" |
| **🗑️ 语音删除日程** | 通过语音软删除已添加的日程             | "删掉周三的例会"            |
| **📋 查询日程**     | 查看某天的日程列表                     | "我这周六有什么安排"        |
| **📅 按日期查询**   | 指定日期查看事件                       | 通过前端日历选择日期        |
| **🔔 近三天汇总**   | 查看未来三天的日程概览                 | 前端一键查看                |
| **💬 语音播报反馈** | 每次操作后语音播报结果                 | "已为您添加日程：..."       |
| **🎙️ 语音文件上传** | 支持上传音频文件进行 ASR 识别          | 上传 .wav / .mp3 文件       |
| **📄 原始指令留存** | 保存用户原始输入，可用于追溯和纠错     | 数据库 raw_command 字段     |

### 技术亮点

- **LLM 驱动的自然语言理解**：告别正则匹配，DeepSeek 解析所有中文日期表达
- **模糊时间匹配删除**：删除操作自动 ±24h 匹配，容错性高
- **软删除机制**：删除仅改状态 (status=2)，数据可追溯
- **全天事件识别**：自动识别"明天提醒我带伞"类全天事件

## 📖 API 文档

### `POST /api/v1/command` — 语音指令处理（核心接口）

接收用户的自然语言指令（文本或音频），通过 LLM 解析意图并执行。

**请求（文本模式）：**

```
POST /api/v1/command
Content-Type: application/x-www-form-urlencoded

text=下周五晚上7点跟女朋友吃饭
```

**请求（音频模式）：**

```
POST /api/v1/command
Content-Type: multipart/form-data

audio: [语音文件]
```

**响应：**

```json
{
  "message": "已为您添加日程：跟女朋友吃饭，时间：2026-06-05 19:00:00",
  "intent": {
    "action": "add",
    "title": "跟女朋友吃饭",
    "time": "2026-06-05 19:00:00",
    "is_all_day": false
  },
  "audio_url": "https://dict.youdao.com/dictvoice?audio=已为您添加日程..."
}
```

### `GET /api/v1/events?date=2026-06-05` — 按日期查询

**响应：**

```json
{
  "events": [
    {
      "id": 1,
      "title": "跟女朋友吃饭",
      "start_time": "2026-06-05T19:00:00+08:00",
      "is_all_day": false,
      "status": 0
    }
  ]
}
```

### `GET /api/v1/events/upcoming` — 近三天日程汇总

**响应：**

```json
{
  "events": [
    { "date": "2026-06-05", "events": [...] },
    { "date": "2026-06-06", "events": [...] },
    { "date": "2026-06-07", "events": [...] }
  ]
}
```

## 🗣️ 语音指令详解

### 添加日程

```json
// 用户说: "下周五晚上7点跟女朋友吃饭"
{
  "action": "add",
  "title": "跟女朋友吃饭",
  "time": "2026-06-05 19:00:00",
  "is_all_day": false
}
```

| 表达方式            | LLM 解析能力         |
| ------------------- | -------------------- |
| "明天上午10点开会"  | ✅ 相对日期           |
| "下周五晚上7点吃饭" | ✅ 下周偏移           |
| "大后天下午3点面试" | ✅ 口语化表达         |
| "这周六提醒我带伞"  | ✅ 全天事件识别       |
| "每周一9点站会"     | ✅ 周期性事件（预留） |

### 删除日程

```json
// 用户说: "删掉周三的例会"
{
  "action": "delete",
  "title": "例会",
  "time": "2026-06-03 00:00:00"
}
```

**删除逻辑：**

1. 标题模糊匹配（`LIKE '%例会%'`）
2. 时间 ±24 小时范围匹配
3. 仅删除 `status=0`（待办）的事件
4. 软删除：将 `status` 更新为 2，不真正删除数据

### 查询日程

```json
// 用户说: "我这周六有什么安排"
{
  "action": "query",
  "time": "2026-06-06 00:00:00",
  "title": ""
}
```

查询结果会返回对应的 `events` 数组，在前端展示。

## 🧠 LLM 意图解析

### 为什么用 LLM 而不是正则？

中文日期表达极其多样：

```
"明天"、"后天"、"大后天"
"下周一"、"下周五"、"下个月15号"
"这周六"、"这周末"、"这周三上午"
"五一前"、"春节后"
"下午3点"、"晚上7点半"
```

用正则：**需要 50+ 条规则，还覆盖不全**  
用 LLM：**一条 prompt 搞定全部**

### Prompt 设计

```go
const systemPrompt = `你是一个日历语音助手。请解析用户的自然语言指令，
返回严格 JSON 格式，不要加任何其他文字。

当前时间：%s

输出格式：
{
  "action": "add | delete | query | update",
  "title": "事件标题",
  "time": "具体时间（格式：2006-01-02 15:04:05）",
  "is_all_day": true/false
}`
```

### 调用 DeepSeek API

- **模型：** DeepSeek Chat（v3）
- **成本：** 极低，每次调用仅几分钱
- **响应时间：** < 1 秒
- **特点：** 中文理解能力强，输出稳定

## 🗄️ 数据库设计

### 表结构：`events`

| 字段          | 类型                        | 说明                                   |
| ------------- | --------------------------- | -------------------------------------- |
| `id`          | BIGINT (PK, AUTO_INCREMENT) | 主键                                   |
| `raw_command` | TEXT                        | ⚡ **原始语音指令**（用于对账和纠错）   |
| `title`       | VARCHAR(255)                | LLM 提取的事件标题                     |
| `start_time`  | DATETIME (INDEX)            | ⏰ **事件时间**（已建索引，查询加速）   |
| `end_time`    | DATETIME (NULLABLE)         | 结束时间（单时间点事件为空）           |
| `is_all_day`  | TINYINT(1)                  | ⚡ **全天事件标记**（"明天带伞"类事件） |
| `status`      | TINYINT                     | 状态：0=待办 1=已完成 2=已删除         |
| `created_at`  | DATETIME                    | 创建时间                               |
| `updated_at`  | DATETIME                    | 更新时间（自动更新）                   |
| `deleted_at`  | DATETIME (NULLABLE)         | GORM 软删除                            |

### 设计要点

```
✅ 单表设计 → 满足 MVP 需求，后续扩展用户表即可支持多用户
✅ start_time 建索引 → 日期查询性能优化
✅ raw_command 保留原始指令 → 可追溯、可纠错
✅ status 软删除 → 数据不丢失，历史可查
✅ is_all_day 标记 → 区分具体时间和全天提醒
```
